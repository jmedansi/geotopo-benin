### Tersus GNSS RTK : le duo base + mobile

Le kit Tersus associe deux récepteurs GNSS RTK, une radio UHF externe et des coffrets de transport renforcés. La configuration base + mobile est pensée pour les chantiers qui exigent une fixation rapide et une portée radio fiable.

Les récepteurs compacts s'installent sur canne ou trépied. La radio externe se connecte à la base pour diffuser les corrections vers le mobile. Le kit comprend les antennes, les câbles, les batteries et les accessoires de mise en station, pour démarrer directement les levés.
